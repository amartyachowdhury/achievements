## YOLO

Making the repo public does not retroactively award badges. [PR #1](https://github.com/amartyachowdhury/achievements/pull/1) did not count because **no reviewer was requested**.

GitHub expects you to:

1. Add a **second GitHub account** (or friend) as a collaborator on this repo
2. Open a PR and **request review** from that account
3. **Merge the PR yourself** before they review it

```bash
YOLO_REVIEWER=other-username ./scripts/yolo.sh
```

Also confirm [Show Achievements on my profile](https://github.com/settings/profile#profile-settings-heading) is enabled in profile settings.
